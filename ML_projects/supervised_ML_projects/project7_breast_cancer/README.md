# 🩺 Breast Cancer Prediction using Machine Learning

A Flask-based Machine Learning web application that predicts whether a breast tumor is **Benign (Non-Cancerous)** or **Malignant (Cancerous)** using the Wisconsin Breast Cancer Dataset.

---

## 🚀 Project Overview

This application allows users to enter clinical breast cancer features and predicts the diagnosis using a trained **Random Forest Classifier**.

The project is built using:

- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy
- Bootstrap 5

---

## 📌 Features

- Interactive Flask Web Interface
- Bootstrap Responsive Design

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/project7_breast_cancer.git
```

Go to project folder

```bash
cd project7_breast_cancer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open browser

```
http://127.0.0.1:5000
```
